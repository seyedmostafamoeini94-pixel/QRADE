QRADE

QRADE (Risk Assessment for Damage and Exposure) is a QGIS Processing plugin for rockfall risk assessment based on the IMIRILAND methodology for landslides in mountainous areas. It combines kinetic-energy raster data with land-cover or exposed-element information to generate GIS outputs, reports, an interactive risk dashboard, and BIM-oriented deliverables.

Requirements

  • QuickOSM is required for Auto land-cover generation from OpenStreetMap data.
  • Auto land-cover mode requires internet access and availability of the Overpass API.
  • Manual land-cover mode can be used offline with suitable local vector data containing a lowercase classification field.
  • QPROTO is recommended for preparing the kinetic-energy raster, but QRADE can use suitable kinetic-energy raster outputs from other rockfall hazard-analysis tools.

Basic Workflow

  1. Prepare a kinetic-energy raster in joules.
  2. Choose Auto OSM or Manual land-cover input.
  3. Choose the default risk-value table or a custom CSV.
  4. Set the temporal probability mode.
  5. Select an output folder.
  6. Run QRADE and review the generated result folder.

Inputs

  • Land Cover Source
  • Extent
  • Risk Assessment Values
  • Area Type and Buildings Typology
  • Kinetic Energy raster (J)
  • Temporal Probability of Occurrence
  • Output Folder and optional GIS layer outputs

Outputs

QRADE creates a timestamped QRADE_Result_TIMESTAMP/ folder with an organized structure:

  • gis/: LandCover, Runout, and Risk Assessment GeoPackage layers.
  • summary/: summary JSON and CSV files.
  • bim/: BIM-ready CSV/JSON, IFC GUID mapping template, and BCF issues folder.
  • reports/qa_qc/: QA/QC HTML, JSON, and CSV reports.
  • reports/web_report/: Interactive Risk Dashboard, data, and assets.
  • risk_tables/: copied custom risk-value table when Manual mode is used.
  • qrade_output_manifest.json: manifest used by the QRADE Smart Assistant.

Smart Assistant

The QRADE Smart Assistant includes:

  • Before running QRADE: Edit Risk Assessment Values.
  • After running QRADE: Select QRADE Result Folder.
  • Reports: Open Interactive Risk Dashboard and Open QA/QC Report.
  • BIM Deliverables: Open BIM-ready CSV, Open IFC GUID Mapping Template, and Open BCF Issues Folder.

Risk Assessment Values

Default mode uses Input/classification_table.csv. Manual mode uses a user-selected custom CSV. The editor opens Templates/classification_table_manual.csv as the editable baseline and saves custom tables in the user QGIS settings directory. Do not edit the packaged Input/ or Templates/ CSV files directly.
