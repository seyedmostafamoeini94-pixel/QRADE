# QRADE Smart QA/QC Assistant

## Overview

The QRADE Smart QA/QC Assistant is a rule-based quality-assurance and quality-control report generated after successful QRADE processing. It reviews existing outputs and metadata to help users inspect warnings, output completeness, and consistency issues.

It is not AI or machine learning. It does not train models, call APIs, use cloud services, or replace expert interpretation.

## Output files

The QA/QC report is written into the timestamped output folder:

```text
qa_qc/
  qrade_qa_qc_report.html
  qrade_qa_qc_report.json
  qrade_qa_qc_report.csv
```

## What the assistant checks

The current Phase 1 report checks:

- output inventory for selected GeoPackage outputs and generated report/export files;
- summary and risk statistics, including feature count, null `risk_total`, maximum risk, and top-risk records;
- classification counts and `Other` warnings;
- BIM export readability, record-count consistency, blank IFC GUID status, and High/Critical BCF priority counts;
- WebGIS report files and risk GeoJSON feature-count consistency;
- temporal probability diagnostics recorded by the main Processing algorithm, including quality status, warnings, event-rate values, and saturation warnings.

## Severity levels

- `PASS`: check passed.
- `INFO`: useful context or expected condition.
- `WARNING`: item should be reviewed.
- `CRITICAL`: serious issue that may affect interpretation.

## Report contents

The reports include:

- run metadata;
- overall QA/QC status;
- severity counts;
- check table;
- recommendations;
- output inventory;
- temporal probability diagnostics;
- classification diagnostics;
- BIM and WebGIS diagnostics.

## How to use the HTML/JSON/CSV reports

Open `qa_qc/qrade_qa_qc_report.html` in a browser for a readable dashboard. Use `qa_qc/qrade_qa_qc_report.json` for structured review or automated checks. Use `qa_qc/qrade_qa_qc_report.csv` when a flat table of checks is easier to inspect or archive.

Warnings should be reviewed before using results for decision-making. A warning is not always an error, but it records an assumption or condition that deserves attention.

## Smart Assistant UI

QRADE now includes a separate `QRADE Smart Assistant` toolbar/menu dialog for opening QA/QC reports, WebGIS reports, BIM deliverables, and the selected output folder. The dialog lets users select a QRADE output folder for the current session and then open available report files.

The dialog also includes a Temporal Probability Estimator.

## Temporal Probability Estimator

The estimator is a helper for checking frequency-based temporal probability assumptions. It uses the homogeneous Poisson formula:

```text
lambda_per_year = N / Tobs
expected_events = lambda_per_year * Tr
equivalent_return_period_years = 1 / lambda_per_year, when lambda_per_year > 0
P_t = 1 - exp(-lambda_per_year * Tr)
```

Terms:

- `N`: number of recorded events.
- `Tobs`: observation period in years.
- `Tr`: assessment/design time window in years.
- `lambda_per_year`: estimated event rate per year.
- `expected_events`: expected number of events in the assessment/design time window.
- `equivalent_return_period_years`: equivalent return period when `lambda_per_year > 0`.
- `P_t`: probability of at least one event in the selected time window.

The estimator is advisory only. Users must manually transfer selected values into the QRADE Processing dialog if they want to use them.

## Smart Assistant UI roadmap

The QRADE Smart Assistant UI should remain a separate toolbar/menu dialog. It should not be forced inside the Processing dialog.

Detailed UI design notes are in `docs/smart_assistant_ui_design.md`.

Implemented first UI version:

- button to open the latest QA/QC report;
- button to open the latest WebGIS report;
- button to open the latest output folder;
- button to select a QRADE output folder;
- buttons to open BIM-ready CSV, IFC GUID mapping template, and BCF issues folder;
- Temporal Probability Estimator;
- clear note that it is rule-based QA/QC, not AI/ML.

Future phases can add last-run summaries, classification guidance, and pre-run checks.

## What it is not

The Smart QA/QC Assistant is not:

- AI or machine learning;
- model training;
- prediction;
- an API or cloud feature;
- a substitute for engineering judgement, field validation, or technical interpretation.

## Current limitations

- Phase 1 relies on files and metadata already generated by QRADE.
- Temporal diagnostics improve review of assumptions, but they cannot determine whether a selected temporal probability model is scientifically appropriate for a specific site.
- The Temporal Probability Estimator is advisory and does not update Processing parameters automatically.
- It does not automatically correct classifications or risk values.
- It cannot determine whether input assumptions are scientifically appropriate for a specific site.

## Planned future QA/QC improvements

- additional temporal probability reporting and guidance;
- classification review suggestions;
- high-risk `Other` feature review;
- richer BIM mapping and BCF readiness checks;
- separate Smart Assistant toolbar/menu dialog.
